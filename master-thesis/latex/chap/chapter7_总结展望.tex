\chapter{总结与展望}
\label{chap:conclusion}

\section{工作总结}
\label{sec:concl-summary}

本文研究智能体大语言模型的持续强化学习，针对"在习得新行为的同时不遗忘已掌握能力"这一核心难题，提出了一个围绕单一主旨组织的端到端方案：\textbf{在持续多轮智能体强化学习中，防止灾难性遗忘不仅要巩固学习信号，更要先保证信号在源头上没有被污染}。全文每一部分都只是两件事之一——在源头把信号做干净，或在不遗忘的前提下巩固这个干净信号。

本文的主要贡献如下：

\begin{enumerate}
  \item \textbf{对持续智能体强化学习的源头级重新表述}。本文识别并形式化了 GRPO 学习信号的两类污染——组内环境发散与多轮前提漂移——它们发生在任何巩固\textit{之前}，且无法用回放或正则化修复。这一重新表述把持续智能体强化学习从单纯的"抗遗忘"问题扩展为"先产出干净信号、再巩固"的两阶段问题。
  \item \textbf{一套产出干净信号的数据与 rollout 系统}。winner 同步会话调度在多查询会话中恢复组内位级一致起点，消除组内环境发散；观察、出题、奖励三个协作智能体在线构造前提成立的多轮数据，根除前提漂移，并兼作跟随策略能力前沿的自适应课程。其中观察智能体以沙箱 before/after 内容级差异为真值、不接收 actor 轨迹，使反奖励作弊成为结构性机制。
  \item \textbf{一套与干净信号匹配的巩固方法}。以零源码改动注入 GRPO 的四项持续学习目标（强化学习、逆向 KL、经验回放、熵正则）；按能力而非难度分区、按抗遗忘价值而非奖励排序的九桶优先级回放缓冲区，桶内淘汰、禁止跨桶挤出；U 形块级回放重加权，把信用集中到每条轨迹的早期分支决策与结论段。
  \item \textbf{系统实现与实验设计}。基于 verl 0.8.0 零侵入落地的端到端训练系统，代码已全部完成并通过约 290 项单元测试；以及在 27B 智能体、九个能力域、Pass$^3$ 评测基准上的 21 个逐组件受控消融实验设计。
\end{enumerate}

\section{局限性}
\label{sec:concl-limit}

本文工作存在以下局限：

\begin{enumerate}
  \item \textbf{U 形与优先级融合权重未实证调优}。$\gamma=\delta=0.88$、优先级四信号融合权重 $(0.4,0.2,0.2,0.2)$（v1 实跑因缺 embedding pipeline 暂禁用 diversity，重归一化为 $(0.5,0.25,0,0.25)$）均为起步值，待 Phase 3 数据校准。短轨迹（小 $K_i$）下 U 形可能近乎消失，需更小 $\gamma$。
  \item \textbf{模拟用户分布失真与幻觉}。42 个人设的分布未必等于真实后续查询分布；观察不全时前提漂移以小概率回归，靠首轮真实锚点与前提成立率审计缓解。
  \item \textbf{观察 grounding 强度等于取证能力}。反奖励作弊的强度上限等于观察智能体能取到的证据强度。二进制格式提取的真值核对需库与真实文件，瞬态或被覆盖的中间产物需事件流（当前只看净变化）。
  \item \textbf{winner 同步进程态保真}。平台若只支持磁盘快照，替补槽的进程/内存态可能与 winner 不一致，这是头号待验证点。
  \item \textbf{实验尚未运行}。受限于 64 卡 GPU 集群与真实模型权重，21 个消融实验均未实际运行，所有结果数字待训练后回填，本文不编造任何结果。
\end{enumerate}

\section{未来工作}
\label{sec:concl-future}

未来工作沿以下方向展开：

\begin{enumerate}
  \item \textbf{完成 21 个消融实验}。在 64 卡集群上跑完 Phase 1--5 全部实验，回填结果数字，验证每个组件的边际贡献，并据负面结果调整方法。
  \item \textbf{Phase 6 探索项}。包括 Forward KL 替代逆向 KL（X6，若 Phase 5 熵仍不稳定）、自适应 $\lambda_4$（X7a，熵阈值反馈）、动态 $\lambda_2$/$\lambda_3$ 调度、桶间亲和度加权回放等。
  \item \textbf{多模态任务扩展}。当前仅用纯文本 195 任务，未来可纳入 ClawEval 的 Multimodal split（101 任务），但需先解决模态不同带来的缓冲区与回放问题。
  \item \textbf{真实用户数据回流闭环}。将线上真实用户的后续查询分布纳入人设库校准，缩小模拟用户与真实分布的差距。
  \item \textbf{FP8 训练探索}。在 Phase 5 大 rollout 量下评估 FP8 rollout-only 模式的吞吐收益与精度代价，配合 Token-level TIS 兜底。
\end{enumerate}
