\section{评测基准与训练方式}
\label{sec:exp-setup}

\textbf{评测基准}采用 ClawEval 的纯文本子集，共 195 个任务，按第\ref{chap:method}章的九个能力域分组。评分采用 Pass$^3$ 标准（三次独立运行全部通过）。

\textbf{训练方式}遵循线上持续学习场景：\textbf{按桶顺序训练}——先在一个能力域上训练至收敛，再切到下一个，同一桶内任务乱序。这模拟了线上数据到达分布不均、无法集齐全分布的现实约束。基座为 Qwen3.5-9B，训练采用完全异步的策略分离部署（推理与训练分卡），BF16 全栈。

\textbf{训练数据组织}：数据按桶排序后，将每个桶的行数截断为训练批大小（\texttt{train\_batch\_size}=32）的整数倍，舍去不足一个完整批次的尾部少量样本（最多 $31$ 行/桶，总计丢弃 $<0.5\%$）。截断后不再有跨桶混合的训练步——每一步中的所有查询均来自同一能力域。这保证每步的 reward 均值、loss 变化严格对应某个特定桶，便于精确追踪桶级学习动态和跨桶遗忘幅度。

\section{按桶抗遗忘评测协议}
\label{sec:exp-eval}

评测遵循\textbf{"训完统一评、权重后置"}的原则：

\begin{enumerate}
  \item \textbf{顺序训练}：按训练序 $b_{\pi(1)}\to\cdots\to b_{\pi(K)}$ 训完全部能力域，训练过程中\textbf{不做中间评测}（省算力）。
  \item \textbf{一次评测}：对终态策略 $\pi_K$ 跑一次评测，评测集按同样的桶分组、组间序与训练序对齐，记录每桶原始分数 $S(\pi_K, b_{\pi(i)})$。此分数固定不变。
  \item \textbf{权重后置}：在固定分数上施加随训练先后衰减的权重 $w_i$（式见第\ref{chap:problem}章），得到加权持续学习得分。衰减形式先试线性、必要时改指数，作为超参由实验确定。
\end{enumerate}

因评测只跑一次，之后换权重方案只是数学计算，无需重新推理，显著省算力。这套协议的核心是刻画"越早训练的桶遗忘越重"，并让\textbf{含持续学习机制}的模型在该指标上相对基线体现出防遗忘收益。

\section{对照与消融}
\label{sec:exp-ablation}

\textbf{核心对照}：含持续学习机制（九桶回放 + 复合损失）\emph{vs.} 无持续学习机制的同规模基线（不加回放、不加持续学习损失，按同样的桶顺序训练、同样的评测）。二者遗忘量对比即为本文方法的防遗忘收益。

\textbf{消融}用于隔离各组件边际贡献，拟考察的轴包括：

\begin{itemize}
  \item \textbf{有无缓冲区}：九桶回放 \emph{vs.} 无回放基线。
  \item \textbf{桶结构 \emph{vs.} 单缓冲区}：九桶分区 \emph{vs.} CLEAR 式单缓冲区（均匀回放 + 蓄水池淘汰）\upcite{A2}。
  \item \textbf{缓冲区容量}：不同总容量下的抗遗忘表现。
  \item \textbf{回放损失加权}：U 形关闭（$\gamma=\delta=1$，主方案）\emph{vs.} U 形开启（$\gamma=\delta<1$）。
\end{itemize}
