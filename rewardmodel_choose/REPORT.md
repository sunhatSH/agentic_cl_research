## 一、测试方法

## 六、选型结论

**当前选择：`openai/gpt-5.6-luna`**（已写入 `configs/agents.yaml`）。

| 维度 | gemini | gpt-5.6-luna |
|------|--------|-------------|
| 旧 prompt reward | 0.878 | 0.694 ← 天花板空间大 |
| 扣分 prompt 效果 | ✗ 完全无效 | ✓ 分布拉开 |
| 稳定性 | 0.004（但打分无效） | 0.036（可接受） |
| 延迟 | 2.2s | 8.9s（可接受） |
| judge_error | 0% | 0% |

**gemini 虽然极其稳定（0.004）且延迟最低（2.2s），但其评分倾向与 prompt 无关——无论是印象评分还是扣分制，都给出几乎相同的 0.85–0.92 分数，导致 reward_max 恒为 1.0，训练无法区分好和更好的轨迹。**

**gpt-5.6-luna 的 reward 均值 0.69 比 gemini 低 0.18，且扣分 prompt 能有效拉开分布。延迟 8.9s 在可接受范围，稳定度 0.036 虽不如 gemini 极端但足够用于训练。**

> 建议：重启训练后观察 gpt-5.6-luna 的 reward 分布是否改善（不再恒 1.0）。如果 top 端仍有天花板，可进一步调整奖励公式（去掉 +0.2 done 基线分）。
