# 内存巡检输出格式说明

## H3C
`display memory` -> `Mem: ... Used: 45%`

## 华为
`display memory-usage` -> `Memory Using Percentage Is: 62%`

## 锐捷
S6000: `show memory` -> `System memory : 70% used`
S5750-6F: 输出 `Used Rate : 38%` 格式, 当前正则不匹配需补充

## 迈普
`show memory` -> `Memory usage: 55%`

## 山石
`show memory` -> `Memory utilization: 40%`
