# Nginx 架构深度研究（全景）

> 本文为系列研究总览，列出 20 个研究模块，每个模块将另起独立深度报告。

## 模块清单

1. **核心特性** —— 高并发处理、异步非阻塞 I/O、事件驱动模型、内存池管理、模块化设计、热部署/平滑升级、反向代理与负载均衡。
2. Master-Worker 进程模型 —— 进程职责划分、信号通信、worker 重启。
3. 事件驱动机制 —— epoll/kqueue 抽象、事件循环。
4. 连接与请求处理流程 —— accept、读写、phase handler。
5. HTTP 模块体系 —— 11 阶段处理。
6. 内存管理 —— ngx_pool_t、slab。
7. 配置解析 —— 指令、上下文继承。
8. 负载均衡算法 —— round-robin、ip_hash、least_conn。
9. 反向代理与 upstream。
10. 缓存机制。
11. SSL/TLS 处理。
12. 日志与监控。
13. 限流与限速模块。
14. 动态模块加载。
15. 第三方模块开发。
16. 性能调优参数。
17. 与 OpenResty/Lua 集成。
18. 容器化与云原生部署。
19. 安全加固。
20. 源码编译与调试。

## 研究方法

- 结合官方文档（nginx.org/en/docs）与源码（src/core、src/event、src/http）。
- 每模块输出独立 Markdown，逐步深入到机制与源码层级。
