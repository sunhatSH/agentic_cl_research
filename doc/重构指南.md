  A. 算法

  A1. CL Loss(核心)

  $$L_{cl} = \lambda_1 L_{rl} + \lambda_2 L_{kl} + \lambda_3 L_{replay} + \lambda_4 L_{ent}$$
  - $L_{rl}$ = GRPO;$L_{kl}$ = reverse KL $D_{KL}(\pi_{new}|\pi_{ref})$;$L_{reg}$(L2)弃用
  - $\lambda_4=0.001$ 固定开(防 Echo Trap,不参与 ablation)

  A2. Reward(本周刚改的新算法)

  if task_done:  reward = 0.4*correctness + 0.4*trajectory + 0.2
  else:          reward = 0.4*trajectory
  reward = reward * safety
  - 全部由外部冻结 LLM judge 打分(correctness / trajectory / safety / done)
  - trajectory 三维:工具调用质量、无冗余/重复步、推理连贯
  - safety 乘性门控(抗 reward hacking)

  A3. Replay Buffer(9 桶,按能力/领域)

  - $L_{replay}$ 权重 = Priority × U 形块权重(首尾高中间低,γ=δ=0.88,按 chat message 边界分块)
