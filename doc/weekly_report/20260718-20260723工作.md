## 3. 4 卡 9B baseline 训练（本周重点）

### 3.1 定位与规模
- **baseline = 按桶顺序训（train_cl.sh --buckets）+ 防遗忘全关**（lambda_replay=0, buffer.enabled=false）；
  CL 版跑同序 + buffer，对比各桶遗忘程度
- 数据源 `queries_train.jsonl`（D 系列，有 9 桶标 + answer_key），record_id → `_load_ground_truth`
  自动注入稠密 reward
- `labeled_to_parquet.py` 加 `--no-system`（走沙箱 Hermes，system 由沙箱注入）+ `--scale`（1/16）
  + `--keep-full`（communication/qa 不缩用全部），按桶分块 parquet
- 规模：train_batch=32 query × n8 = **256 轨迹/step**（GRPO 统计量下限）；micro=1；
  max_prompt=2048（实测 max 708）；max_response=53886（claude opus 轨迹 p90）；每桶 steps=条数/32

### 3.2 训练 rollout 打通（连修 8 个坑）
从启动到真正反向传播，逐个定位修复：
1. logger oc.decode `UnsupportedValueType` → 字面 list
2. verl `AgentLoopConfig` 多字段 TypeError → 只留 agent_loop_manager_class
3. swanlab 422 中断 → 去 swanlab 留 console（指标/rollout/val/ckpt 全落本地）
4. coroutine 未 await → generate_sequences 加 `@auto_await`（对齐 verl 基类）
5. E2B 凭证缺失 → train_cl 真训练也 source load_tencent_env
6. tokenizer None（基类不持有）→ 从 model_config.path 自加载
7. **用错采集路径**（hermes CLI stdout，response_token_ids=[]）→ 改
   `make_react_agent_fn + VerlRolloutGenerateFn`：agent 在沙箱跑 ReAct，每步生成走 verl
   LLM server（lightllm 后端）原生带回 token+logprob（GRPO 必需）
8. Qwen3.5 apply_chat_template 返 BatchEncoding（非 dict）→ list() 拿到 key 字符串 →
   lightllm "prompt format error" → 提取 input_ids
