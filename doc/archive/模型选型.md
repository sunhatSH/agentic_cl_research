## 2. 选型约束（为什么这么选）

- **三 agent 互不为同一模型**（`observer`/`questioner`/`reward` 各自独立模型）→ **抗 self-preference**（同一模型既观察又出题又阅卷会偏袒自己）。
- **Questioner 多模型轮换**：`questioner.rotation` 4 个跨厂商模型，每 5 次 `chat()` 切换，防 follow-up query 模式坍缩。
- **Persona tone 注入**：persona 的 `tone`（calm/neutral/hot）注入 Questioner system prompt。
- **Observer 温度 0**：客观取证，确定性。
- **Questioner 温度 0.9**：多样性，抗 follow-up 模式坍缩。
- **Judge 冻结 + ≥ 策略容量**：reward 必须是不变的尺子（跑数周/多实验测遗忘，避免版本漂移污染遗忘度量）；`claude-4.8-opus` 能力远超 27B 策略以抗 reward-hacking，冻结由 sufy 托管保证；判分对象 = ClawEval 三维 rubric（`safety*(0.8·completion+0.2·robustness)`），与评测同构。
  > 注：原选 `claude-opus-4-8-thinking`（thinking 模型），切 sufy 后改 `claude-4.8-opus`（sufy 上对应的最强 opus）。thinking 模型 judge 易吃光 max_tokens 导致 `judge_error=1.0`，已把 judge `max_tokens` 提到 4096 + 加三档打分锚点（见 `trainer/model_reward.py` / `agents/prompts.py`）。

## 3. Judge 校准（可选验证，非阻塞）

- **一致率校准（可选）**：`scripts/calibrate_judge.py` + `eval/judge_agreement.py` 可在有 ClawEval 人工标注数据时，量化"judge 打分 vs 人工"一致率（MAE / pearson / kappa / F1，按桶分解），验证所选 judge 是否够格。
  - 非选型阻塞：选型由 @孙豪 拍板。校准是上集群后**可选质量验证**；标注数据（@杨益博 manifest）到位就能跑，没到位也不影响用既定 judge 开训。

## 5. 温度策略（按"是否需要组内多样性"分档）

温度**不能一刀切**，取决于采样目的：训练 rollout 要**探索性方差**，冷启动要**高质量锚点**。

| 用途 | 温度 | 理由 |
|---|---|---|
| **训练 rollout actor**（Qwen3.6-27B, GRPO 8 路） | **1.0** | GRPO 靠同 query 8 条轨迹的 reward **方差**算 advantage；温度低→组内趋同→advantage≈0→梯度消失。这是算法刚需，不能动（同 §Echo Trap / `trajectory_diversity` 监控）。 |
| **冷启动单路采集**（`collect_rollout.py` slots=1，无 GRPO） | **0.4** | 单路无组内多样性需求；目的是采**防遗忘锚点**（agent 多步工具任务要"做对"）。高温只会让工具调用/决策发散出错，把低质轨迹掺进 buffer。**on-policy(27B) 与 off-policy(gpt-5.5) 两 actor 同用**（`collect_rollout.py --temperature` 默认已改 0.4）。 |
| **冷启动 GRPO 多路**（`collect_cold.py` / `sandbox_grpo_collect.py`） | **1.0**（暂不动） | 有 winner-sync，需一点组内方差选 winner。当前保持 1.0；若发现 loser 槽大面积失败浪费采集，可降到 ~0.7（未改，记此备选）。 |
| Observer | 0.0 | 客观取证，确定性。 |
| Questioner | 0.9 | 出题多样性，抗 follow-up 模式坍缩。 |
| Reward / Judge | 0.0 | 冻结尺子，一致性。 |

> **2026-07-03 修正**：冷启动单路采集温度由 1.0→0.4（@孙豪 反思：agent 任务采锚点不该高温发散）。改动落点 = `scripts/collect_rollout.py` 的 `--temperature` 默认值。训练 rollout 的 1.0 与三 agent 温度不变。
