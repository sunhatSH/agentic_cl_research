# UserSim 人设库（Questioner Personas）

> 16 个固定 Questioner 人设。每个会话随机抽 1 个、整场固定。

## 因素说明

每个人设由以下因素刻画：

- **职业**：人设身份。
- **在意什么**：生成下一轮 query 时的侧重点。
- **观察偏好**：关注哪一面 = {细节 | 整体} × {内容 | 形式}。
- **P0（初始耐心）**：愿意给几次机会。
- **d0（耐心衰减）**：失败时耐心掉得多快。
- **重试≈**：放弃前的重试次数 ≈ log₂(P0 / d0)。
