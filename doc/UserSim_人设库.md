# UserSim 人设库（Questioner Personas）

> 42 个 Questioner 人设（16 基础身份 × 语气，砍掉违和组合后）。每个会话随机抽 1 个、整场固定。

## 因素说明

每个人设由以下因素刻画：

- **职业 / 在意什么**：身份，以及生成下一轮 query 时的侧重点。
- **观察偏好**：关注哪一面 = {细节 | 整体} × {内容 | 形式}。
- **P0（初始耐心）/ d0（耐心衰减）**：愿意给几次机会 / 失败时耐心掉得多快。放弃前重试次数 ≈ log₂(P0 / d0)。
- **语气**：怎么说，**与耐心独立**——冷静 / 居中 / 暴躁。

| 语气 | 表达方式 |
|------|---------|
| 冷静 | 克制、就事论事，即使不满也保持礼貌 |
| 居中 | 直白、有情绪但不失态 |
| 暴躁 | 强烈、可带责备/讽刺/脏话 |

**语气受耐心约束**：越没耐心越可能暴躁，越耐磨越倾向冷静。**耐磨人设（重试≈≥3.7）禁用暴躁**，只配冷静/居中——避免"很有耐心的人破口大骂"的失真。急脾气配冷静则保留（秒放弃但礼貌）。
