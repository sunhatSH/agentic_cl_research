# 9B 16GPU 训练配置与显存核算

2026-07-24

## 硬件规格

| 项 | 值 |
|---|----|
| GPU | H800 80GB × 16 |
| 节点 | 2 × 8 卡 |
| 模型 | Qwen3.5-9B, bf16 |
| 框架 | verl 0.8.0 + LightLLM + FSDP |
| 推理后端 | LightLLM async, TP=2 |

## 并行策略

| 维度 | 值 | 说明 |
|------|-----|------|
| FSDP DP | 8 | 模型权重分 8 份，16÷SP2 |
| Ulysses SP | 2 | 长序列切分 |
| TP (推理) | 2 | LightLLM 张量并行 |
| 总并行度 | DP=8, SP=2, TP=2 | 16 卡全部参与 |

## 显存分配

```
H800 每卡 80GB
├── 推理侧 LightLLM          80 × 0.40 = 32GB
│   ├── 模型权重 (TP=2)      9GB  (18GB ÷ 2)
│   └── KV cache 池          23GB → ~640k token
│       └── 8 session/TP组 × 均5k token = 40k → 利用率 6%
│
├── 训练侧 FSDP              80 - 32 = 48GB
│   ├── Actor shard (DP=8)   2.25 GB
│   ├── Ref shard (DP=8)     2.25 GB  (KL实验时)
│   ├── all-gather 峰值       9 GB
│   ├── 激活值 micro=2       12 GB
│   └── CUDA 杂项             3 GB
│   ──────────────────────────────
│   合计                     ~28 GB → 余量 20GB
```

| TP 组数 | 8 | 16÷TP2 |

| agent max_turns | 16 | Hermes ReAct 内循环上限 |
| 多轮追问 | 关 | multi_turn.enable=false |

## 实验矩阵（15 个实验，全部独立）

### Phase 1 — baseline
| 实验 | KL | replay | buffer | 说明 |
|------|-----|--------|--------|------|
| B1 | - | - | - | 遗忘下界对照 |

### Phase 2 — KL 扫描
| 实验 | kl_coef | replay | 说明 |
|------|---------|--------|------|
| K1 | 0.01 | - | 弱 KL |
| K2 | 0.05 | - | 中 KL |
| K3 | 0.10 | - | 强 KL |

### Phase 3 — Buffer 消融矩阵
```
                CLEAR(1桶)      9桶+priority
  λ=0.3         R0-03              R9
  λ=0.5         R0-10k       R3 R7 R8 R4
  λ=0.8         R0-08              R6
```
R3/R7/R8/R4 构成 2×2 消融：uniform/distance 桶采样 × uniform/anti-forgetting priority

### Phase 4 — 交互验证（待定）
K2-R, R4-K — 等 Phase 2+3 出最优值后定参

## 训练产出

| 输出 | 路径 | 说明 |
|------|------|------|
| 训练日志 | `logs/experiments/{exp}/train.log` | 全量 shell + Python 输出 |
| 训练指标 | `logs/metrics/{exp}/training_metrics.jsonl` | 每步 reward/loss/KL/entropy/replay_loss |
| Winner 轨迹 | `logs/experiments/{exp}/rollout/winners.jsonl` | 每条 winner 完整 messages + reward |
| Buffer 状态 | `logs/buffer_stats/{exp}.jsonl` | 每桶大小、填充率、priority |
| Rollout 生成 | `logs/experiments/{exp}/rollout/{step}.jsonl` | verl 原生文本 + 分数 |
| Checkpoint | `ckpts/{exp}/global_step_*/` | 每 100 步保存 |
