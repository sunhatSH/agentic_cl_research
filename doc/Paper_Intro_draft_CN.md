## 一句话主旨（记住它，一切都服务于它）

> **在多轮 agentic LLM 的持续 RL 中，防止灾难性遗忘不仅要"巩固"学习信号，更要先保证信号在源头上没有被污染。**

全文的每一部分都只是两件事之一：(a) *在源头把信号做干净*，或 (b) *在不遗忘的前提下巩固这个干净信号*。没有任何一个组件被当作独立的 trick 来卖。

## 1 引言

线上 LLM agent 通过周期性的强化学习更新来进步：每隔几周，用新采集的交互数据精炼策略。这本质上是**持续强化学习**——模型必须在习得新行为的同时保住已有能力。在 agentic、多轮的设定下，有两个失败模式让这件事变难。其一是**灾难性遗忘**：在新任务上的更新侵蚀此前已掌握领域的性能。其二是 **Echo Trap** [B4]：多轮 agentic RL 中策略多样性坍缩，组内 rollout 趋于一致，训练停滞或发散。已知强化微调比监督微调更不易遗忘 [B2, C1]，但它仍会遗忘，且多轮 agentic 场景带来了单轮研究暴露不出的失败模式。

针对遗忘的主流解法——经验回放 [A2]——及其各种改进（优先级 [A9]、分区 [A3]、压缩 [A8] buffer）都共享一个隐含假设：被回放的与在线的经验携带着*忠实*的学习信号。我们主张，在持续**多轮 agentic** RL 中这个假设会悄悄破裂，而且破裂发生在任何 replay 或正则**之前**。这些 agent 的主力算法 GRPO 通过对同一 query 的 $M$ 条 rollout 在组内归一化来估计每条样本的 advantage。这个估计**仅当** $M$ 条轨迹的差异纯粹来自策略采样随机性时才无偏。两个典型的 agentic 效应在源头破坏了这个前提：

1. **组内环境发散。** 跨多 query 会话，$M$ 个执行环境逐渐分叉；某个槽可能并非因策略更差、而是因前一条 query 留下的不利状态被惩罚，于是 advantage 吸收了随轮次累积的环境噪声。
2. **多轮数据的前提漂移。** follow-up query 通常引用上一轮的结果（"第 3 页的数据错了"）。当 follow-up 在数据采集时写死、而实际状态是策略相关的随机函数时，其前提只以一个*随策略变强而漂移*的概率成立——于是奖励了对不存在问题的幻觉式修复，或惩罚了如实回答"没有这个问题"。

被污染的 advantage 在下游无法修复：任何 replay 加权或 KL 锚定都救不回一个符号本就错了的梯度。这把持续 agentic RL 重新表述为一个**两阶段**问题——先产出干净信号，再巩固它——并把我们的整个系统围绕这一主旨来组织。

**在源头把信号做干净。** 我们用一个沙箱 rollout 系统来满足 GRPO 的前提：每组 $M$ 个槽从同一母版派生、起点位级一致，并在每个轮次边界把会话对齐到*优胜*轨迹，使下一条 query 的组再次从共同状态出发（消除发散 #1）。我们消除前提漂移（#2）的办法是：每个真实会话只保留第一条 query 作种子——数据里真实的后续 query 本身绑定于原始执行结果，直接复用会遭遇同样的漂移——其余每一轮都**在观察到实际状态之后在线构造**，由三个协作 agent 完成——无人设的**观察 agent** 收集实际中间与最终结果的客观报告，带人设的**出题 agent** 基于该报告提出下一条 query，**奖励模型** 基于同一份报告对该轮打分。由于每条 follow-up 都是在状态被观察之后写出的，其前提由构造保证成立。

**在不遗忘的前提下巩固干净信号。** 在干净信号之上，我们施加一个注入 GRPO、不 fork trainer 的四项持续学习目标（RL、reverse-KL、replay、entropy）；一个按*能力*而非难度分区、按*抗遗忘价值*而非 reward 排序的 replay buffer；以及一个 U 形、按动作块的 replay loss 重加权，把信用集中到每条轨迹的早期分支决策与结论段。

我们在一个 27B agent 上跨七个能力域验证整套系统，用 Pass³ 基准同时量化新任务习得与旧任务遗忘，并以受控消融套件隔离每个组件的边际贡献。`[TODO: 结果——相对 CLEAR 与纯 RL baseline 的遗忘/CL-Score 头条数字]`

### 贡献

在单一主旨下，我们的贡献是：

1. **对持续 agentic RL 的源头级重新表述。** 我们识别并形式化了 GRPO 学习信号的两类污染——组内环境发散与多轮*前提漂移*——它们发生在巩固*之前*，且无法用 replay 或正则修复。（§3）
2. **一个产出干净信号的数据/rollout 系统。** winner 同步会话调度在多 query 会话中恢复组内位级一致起点；三 agent（观察 / 出题 / 奖励）模拟用户流水线在线构造前提成立的多轮数据，并兼作一个跟随策略能力前沿的自适应课程。（§4.4–§4.5）
3. **一个与干净信号匹配的巩固方法。** 零 fork 注入的四项 CL 目标、按能力分区的抗遗忘 replay buffer、以及 U 形块级 replay 重加权。（§4.1–§4.3）
4. **一次大规模验证。** 27B agent、七个领域、Pass³ agentic 基准上的逐组件受控消融。`[TODO: 结果]`（§5–§6）

> **关于叙事纪律的说明。** 贡献 2 和 3 刻意**不**作为一串独立 trick 来呈现；每一项都是服务于"先产出、再巩固一个未被污染信号"这一单一主旨的手段。在消融（§5）中，每个子组件都必须对着这个主旨挣到自己的位置；任何在干净信号机制下不改善遗忘的子组件，将作为负面结果如实报告，而非强行辩护。
